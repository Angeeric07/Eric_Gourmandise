# 🍽️ Restaurant Web App - Carte & Réservation

Une application web interactive et responsive permettant d'explorer le menu d'un restaurant par catégories et d'effectuer une réservation directement via **WhatsApp**.

---

## 🚀 Fonctionnalités

* **Affichage dynamique du menu :** Cartes générées automatiquement en JavaScript à partir d'une liste d'objets.
* **Filtrage par catégorie :** Filtre instantané des plats (Entrées, Plats, Desserts, Boissons) au clic sans rechargement de page.
* **Boutons interactifs :** Gestion dynamique de l'état actif des filtres avec feedback visuel.
* **Réservation WhatsApp :** Formulaire de réservation qui génère et pré-remplit un message personnalisé envoyé directement sur WhatsApp.
* **Design Responsive :** Interface adaptée aux mobiles, tablettes et ordinateurs grâce au CSS Grid et aux Media Queries.

---

## 🛠️ Technologies utilisées

* **HTML5** : Structure sémantique de la page.
* **CSS3** : Flexbox, CSS Grid, variables, et Media Queries.
* **JavaScript (ES6+)** : Manipulation du DOM, gestionnaires d'événements (`addEventListener`), et méthode `forEach`.
* **Google Fonts** : Typographie Poppins.
